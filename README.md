# COTIZIA

Application web de gestion de tontines, de cotisations ou de fonds mutuels développée en Java (Jakarta EE).

## Technologies
- Java 19
- Jakarta EE 10
- Maven
- MySQL & HikariCP
- JSP / JSTL

## Lancement
Pour lancer le projet en local avec Jetty :
```bash
mvn clean jetty:run -Djetty.port=8082
```
L'application sera accessible sur `http://localhost:8082`.
